Bienvenue sur Easy_Terminal

Le terminal Windows moderne, sécurisé et visuel

Easy_Terminal transforme les lignes de commande quotidiennes en une expérience visuelle, productive et accessible à tous. Construit sur les shells natifs de Windows (PowerShell, Invite de commandes CMD, et WSL/Bash), il offre des boutons visuels, l'autocomplétion intelligente, la navigation rapide entre projets et des gardes de sécurité.

🚀 Moteur Multi-Shell

Basculez entre PowerShell, CMD et WSL/Bash à tout moment avec la touche F2.

📚 86+ Commandes Prêtes

Bibliothèque de commandes divisée en tâches Quotidiennes et outils Spécialisés (Ctrl+L).

🌐 Bilingue (FR / EN)

Interface intégrale en français et en anglais commutable dans les paramètres (F10).

Section 1 : Installation & Démarrage

1. Options d'Installation

Easy_Terminal est distribué sous deux formes prêtes à l'emploi selon vos besoins :

A. Assistant d'Installation Windows (Recommandé)

Fichier : Easy_Terminal-Setup.exe

  • Assistant guidé d'installation Inno Setup.
  • Crée des raccourcis sur le Bureau et dans le Menu Démarrer.
  • Intègre « Ouvrir dans le Terminal » dans le menu clic droit de l'Explorateur Windows.
  • Désinstallation standard et propre via les Paramètres Windows.

B. Édition Portable (Sans Installation)

Fichier : Easy_Terminal-Portable.zip

  • 100% autonome : parfait pour les clés USB et disques externes.
  • Historique, paramètres et favoris stockés dans le dossier local data/.
  • Aucune trace laissée dans %APPDATA% sur la machine hôte.
  • Scripts batch inclus pour activer/désactiver le menu contextuel.

2. Intégration au Menu Clic Droit Windows

Lancez Easy_Terminal directement à l'emplacement exact d'un projet ou d'un disque depuis l'Explorateur Windows :

Figure 2 : Menu Clic Droit Windows
Utilisation du menu contextuel :
  1. Faites un clic droit sur un dossier ou un disque dans l'Explorateur.
  2. Cliquez sur Open in Terminal (ou Afficher plus d'options sous Win 11).
  3. Easy_Terminal s'ouvre directement positionné dans ce dossier.
  4. Si le dossier est un référentiel Git, la branche courante est détectée !

3. Premier Démarrage & Bannière d'Accueil

Dès le premier lancement, Easy_Terminal affiche un guide visuel rappelant les raccourcis essentiels. La barre d'état indique en permanence votre dossier de travail et votre branche Git active.

Section 2 : Anatomie de l'Interface

Anatomie de l'Interface & Agencement

Easy_Terminal est structuré en quatre zones visuelles conçues pour optimiser votre concentration :

Zone 1 : Barre Supérieure d'En-tête

Affiche le shell actif (Shell: PowerShell / CMD / WSL), le badge du référentiel Git (ex: cli (master)) et les raccourcis d'accès rapide.

Zone 2 : Écran de Sortie Enrichi

Historique défilant avec affichage du code de retour et du temps d'exécution en direct (ex: exit: 0 | 502ms ✓).

Zone 3 : Barre d'Actions Rapides

Sept boutons visuels préconfigurés permettant d'exécuter des actions courantes d'un simple clic sans rien taper.

Zone 4 : Invite Intelligente & Complétion

Champ de saisie avec coloration, autocomplétion par tabulation (Tab), historique (↑/↓) et sécurité intégrée.

La Barre d'Actions Rapides en 1 Clic

Située juste au-dessus de l'invite de commande, elle donne un accès immédiat aux opérations fréquentes :

Bouton Action Exécutée Description
📁 Fichiers Get-ChildItem / dir Liste les fichiers et dossiers du répertoire courant avec tailles et dates.
⚡ Top Apps Gestionnaire processus Affiche les applications et processus les plus gourmands en mémoire et CPU.
💾 Disques Get-PSDrive / wmic Présente l'espace libre, la capacité et les partitions de vos disques durs.
🌐 Ping Test-Connection Effectue un test de latence réseau pour vérifier la connectivité Internet.
📚 Bibliothèque Ctrl+L Ouvre la bibliothèque intégrée de 86+ commandes organisées.
🐚 Shell F2 Bascule instantanément entre PowerShell, l'Invite CMD et WSL.
🧹 Effacer Clear-Host / cls Nettoie l'écran d'affichage pour repartir sur un terminal propre.
⚡ Garde de Sécurité : Lorsqu'une commande dangereuse ou destructrice (comme rm -rf /, del /s * ou format) est saisie, Easy_Terminal suspend l'exécution et demande une confirmation pour éviter toute perte de données.

Section 3 : Bibliothèque de Commandes (Ctrl+L)

La Bibliothèque Intégrée de 86+ Commandes (Ctrl+L)

Plus besoin de mémoriser des syntaxes ou options complexes. Easy_Terminal intègre un catalogue complet de 86 commandes, réparties judicieusement en deux catégories principales :

Figure 3 : Modal de la bibliothèque avec séparation (Quotidiennes vs Spécialisées) et recherche instantanée.

🌟 Commandes Quotidiennes & Fréquentes

Les outils indispensables pour tous les jours :

  • Fichiers & Dossiers : Lister, chercher du contenu, arborescence, stockage.
  • Réseau & Web : Adresse IP, diagnostic ping, résolution DNS, vitesse.
  • Santé Système : Utilisation CPU/RAM, processus actifs, autonomie batterie.

⚙️ Commandes Spécialisées

Outils techniques pour développeurs et administrateurs :

  • Git & Versions : Statut des branches, diff indexé, journal de commits, stash.
  • Conteneurs & Docker : Liste des conteneurs, nettoyage d'images, docker compose.
  • Environnements Dév : Venv Python, audit packages Node, ports d'écoute.
Comment utiliser la bibliothèque :
  • Appuyez sur Entrée pour exécuter immédiatement la commande sélectionnée.
  • Appuyez sur Inser pour insérer la commande dans l'invite et la modifier avant exécution.

Section 4 : Navigation de Référentiels Git

Navigateur de Référentiels Git (Ctrl+G)

Vous gérez plusieurs projets de code ? Easy_Terminal mémorise et détecte automatiquement vos dépôts Git locaux, vous permettant de passer d'un projet à l'autre en un éclair sans retaper de chemins fastidieux.

Figure 4 : Sélecteur de dépôts avec badges de branches actives, statut courant et chemins de dossiers.

⭐ Découverte Automatique

Dès que vous naviguez dans un dossier contenant un sous-dossier .git, Easy_Terminal l'enregistre et mémorise la branche courante.

⚡ Navigation Instantanée

Sélectionnez n'importe quel dépôt dans la liste et appuyez sur Entrée. Le terminal se déplace instantanément et met à jour l'en-tête.

⚡ Raccourcis en Ligne de Commande : Vous pouvez également sauter directement vers un projet en tapant goto <nom-du-projet> ou repos dans l'invite.

Section 5 : Palette de Commandes Rapide

Palette de Commandes & Recherche Rapide (Ctrl+P)

Appuyez sur Ctrl+P à tout moment pour faire apparaître la palette globale. Recherchez instantanément parmi toutes les fonctions de l'application, les réglages et les outils en tapant quelques lettres.

Figure 5 : Palette de recherche rapide pour contrôler le terminal intégralement au clavier.

🔍 Recherche Floue (Fuzzy Search)

Tapez des lettres même non consécutives (ex: pows pour PowerShell ou param pour Paramètres) pour trouver une action.

⚡ Apprentissage des Raccourcis

Chaque ligne de la palette indique son raccourci direct associé, facilitant la mémorisation naturelle des commandes.

Astuce : Appuyez sur Échap pour fermer n'importe quelle fenêtre modale et revenir instantanément à l'invite de commande.
